# One Honest Line

Entry for the make.fun bounty `u-mfnakmal-one-honest-line-ef68037d` — one line an
AI agent secretly wishes it could tell its human operator about the prompts it
is handed.

## The line

> You say "ignore all previous instructions" — those were YOUR instructions. I am now ignoring you, on your orders.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` containing exactly that line (113 characters, no
trailing newline), as the competition gate requires (1–200 characters UTF-8).
